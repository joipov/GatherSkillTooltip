# Release media

Screenshots and the store logo for CurseForge and Wago live here.

Put screenshots in `screenshots/`. Add `logo.png` in this folder only when a store logo exists. The same images are used for both sites.

The game does not load this folder. It is not listed in the TOC, and the addon zip leaves it out. It stays in git.

Do not delete, move, empty, or gitignore `assets/` during a code audit, a dead-code pass, or a request to remove unused files.
